# 角色制作 — 用 JSON 做一个 NPC

**零代码。** 往 `npc/personas/` 放一个 `<id>.json`，重启服务器，角色就活了。

```bash
# 启动时指定自己的角色目录(或直接放进默认目录 npc/personas/)
python -m npc.server --persona-dir npc/personas --no-browser
```

## 字段说明

| 字段 | 必填 | 说明 |
|------|------|------|
| `id` | ✅ | 角色唯一 ID（API 调用用这个） |
| `identity` | ✅ | 身份/背景一句话 |
| `personality` | ✅ | 性格 |
| `speech_style` | ✅ | 说话风格 |
| `taboos` | ✅ | 禁忌（数组，可空） |
| `name` | — | 显示名，缺省 = id |
| `rules` | — | 规则话术：`{"replies": {"关键词": "回复"}, "fallback": "兜底句"}` — LLM 不可用时用 |
| `desires` | — | 欲望（对象，进对话上下文） |
| `goals` | — | 目标（对象，进对话上下文） |
| `routine` | — | **自主日常作息表**（见下） |
| `context_extra` | — | 自定义状态展示（好感度/情绪等，字符串数组） |
| `system_prompt_override` | — | 完整覆盖系统提示词（高级） |

## routine — 自主日常作息表

NPC 不跟玩家说话时**自己过日子**，按权重随机挑日常：

```json
"routine": [
  {"action": "gather", "resource": "木材", "count": 2, "weight": 4},
  {"action": "rest",   "ticks": 3,             "weight": 2},
  {"action": "gather", "resource": "浆果", "count": 1, "weight": 1}
]
```

| action | 参数 | 行为 |
|--------|------|------|
| `gather` | `resource`（木材/浆果/石头）+ `count` | 走到资源点 → 采集 count 次 → 运回 → **自动交付** |
| `rest` | `ticks` | 原地休息 N 个 tick（可能碰面说台词） |
| `say` | — | 碰面时说一句规则台词 |

`weight` 越高越常被选中。失败项自动冷却 5 个 tick 再重试；资源回补由世界 `_resource_regen` 声明（参考世界 = 每 tick 回补 1，上限 `_resource_caps`），**未声明则采空后不恢复**。

## 完整示例

```json
{
  "id": "cang",
  "name": "苍",
  "identity": "部落的老猎手，营地的顶梁柱。打猎、伐木、看天色，样样在行。热爱合作",
  "personality": "沉稳、话少但靠谱，答应的事一定办到",
  "speech_style": "话不多，句句落地，偶尔带点老一辈的教训",
  "taboos": ["浪费食物", "丢下同伴"],
  "rules": {
    "replies": {
      "狩猎": "别追跑得快的，盯住掉队的。",
      "木材": "柴火要挑干透的，湿柴烧起来全是烟。"
    },
    "fallback": "嗯，火塘边坐着说。"
  },
  "routine": [
    {"action": "gather", "resource": "木材", "count": 2, "weight": 4},
    {"action": "rest",   "ticks": 3,             "weight": 2},
    {"action": "gather", "resource": "浆果", "count": 1, "weight": 1}
  ]
}
```

## 记忆卡（运行时自动生成）

服务器运行时每个角色生成 `npc/store/<id>_memory.json`：
- 自动记录任务日志 + 加权记忆
- **可直接打开编辑**（改完重启生效）
- 已加入 `.gitignore`，不会提交到仓库

## 常见问题

- **改了 JSON 不生效** 重启服务器（角色表以 JSON 为准，记忆卡里的 persona 会被覆盖）
- **NPC 不动** 检查 routine 是否为空或全部被冷却；resource 名称是否在世界里有对应资源点
- **想让它拒绝订单** 资源采空时它自动诚实拒绝——不用写代码
