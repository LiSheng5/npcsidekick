## 1. 背景

任务回路 v1.9 已落地（提交 8a84948），review 留下三个结构性问题：

- **A 派发事件写在读路径**：`server.py` 的 `_dispatch_with_log` 在 GET /api/state
  （轮询读端点）里做写副作用，并用内存 `_dispatched_seen` 集合去重——若 mod
  断连/客户端只走 /api/events，派发事件永远进不了世界日志与归档。
- **B 动作呈现硬编码**：`NPC._task_desc` / 承诺 ack 是 if-分支特判
  （goto/follow_player/gather 各一份），而 manifest（`reviewer.py` 的
  `get_manifest` / `npc/adapters/gta_actions.json`）是项目声明的动作真相层
  ——加一个动作要改 3+ 个文件。
- **C 地点识别是临时的**：`_clean_place` 固定尾词表 + 10 字硬截断，长地名
  被截成别的地名 → mod 地标表查无 → 玩家莫名收到任务失败商议。**用户已拍板：
  深度版 = 地点词典由 world/manifest 声明驱动，与资源词典同款。**

## 2. 目标与验收

### A ledger 事件队列（book→dispatch 转换即事件）

- `npc/taskloop.py::TaskLedger` 加派发事件队列（与 `_discussions` 同款
  "pop 即消费"模式）：`dispatch_view()` 里 booked→dispatched 转换那一刻
  append 事件；新增 `pop_dispatch_events()` 供 server 消费
- `server.py`：删 `_dispatch_with_log` 闭包与 `_dispatched_seen` 集合，
  GET /api/state 的 `pending_tasks` 直接 `dispatch_view()`（**响应结构不变**）；
  `_tick_loop` 每帧 flush 事件 → `world["log"].append(f"{npc_id} 接下任务: {desc}")`
  （日志行格式不变，与 `events_archive.parse_log_line` 的 task 正则对齐）
- 验收：mod 断连/不 poll 也不丢派发事件；同一任务只在转换时写一次日志
  （断连重连、多客户端 poll 均不重复）；`/api/events` 增量流含 task started 事件

### B manifest 动作模板（动作呈现单一来源）

- 动作 spec 新增**可选**字段 `desc_tpl` / `ack_tpl`（带 `{地点}`/`{resource}`/
  `{count}` 占位符）；`load_manifest` 校验不强制（缺省回退代码内置）
- `NPC._task_desc` / 承诺 ack：优先读 `_manifest_spec(action)` 的模板并
  `str.format` 填充，缺省回退现有硬编码分支（行为零变化）
- `npc/adapters/gta_actions.json` 给 follow_player/goto 补模板；默认内置清单
  的 gather 可补模板或保持代码默认（二选一，写明理由）
- 验收：新增 `drive_to` 类动作时只改 manifest 一处即完成 desc+ack；
  gta_actions.json 加载后 goto 的 desc/ack 措辞与模板一致

### C 地点词典（深度版，用户已拍板）

- `npc/reviewer.py` 新增 `load_place_lexicon_from_world(world, extra)`：
  同款收集规则——`world["locations"]` 的 key 为规范地名，每 location 可选
  `aliases` 列表进同义族；manifest 可选 `places` 段（与 `resources` 段同款，
  `set_manifest_resources` 同款暂存）作 extra
- `get_place_aliases()` 当前生效词典（未加载 → None）
- `_compile_move_task` 的 goto 提取改：词典**最长匹配**优先（"河边" 在
  "陪我去河边吧" 里命中）→ 归一成规范地名；词典未加载时回退现有尾词清洗
  （行为零变化）；截断 10 字仅作最后兜底
- 验收：词典加载后长地名不截断、别名归一到规范名（mod 地标表查得到）；
  词典未加载（默认清单世界）行为与旧版逐字节一致
