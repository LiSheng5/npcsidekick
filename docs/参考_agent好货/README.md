## 已知坑（拿去用之前必须知道）

- **02 的默认嵌入模型 all-MiniLM-L6-v2 是英文模型**，中文记忆卡效果差——
  正式启用前要换中文嵌入（如 bge-small-zh），且 chromadb 是重依赖，
  按家规做成默认关的开关（NPC_VECTOR=1 这类）。
- **01 重试会拉长响应**，必须和现有超时预算对表（talk 60s / mod HTTP 120s），
  不能盲试三次把预算烧光。
- 03/04 是设计参考为主，代码要按大脑侧的实际结构重写。
