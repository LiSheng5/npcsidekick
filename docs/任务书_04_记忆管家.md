## 1. 背景与目标

现状三个动作各自为政：反思（20 tick 体检+阈值 18）、遗忘合并（60 tick）、
画像更新（黎明跨点，§26 已拆出）。缺一个**统一推进与管理**的层，且
没解决：①自主日志滚窗后无摘要归档 ②记忆卡超阈值无应急 ③人工编辑无保护。

**管家 = 一个循环 + 三触发器**，一次整理跑完：扫描 → 分档 → 压缩 → 归纳 → 画像。

## 2. 触发器（用户已拍板：不绑"睡觉"）

| 触发 | 判定 | 干的事 |
|---|---|---|
| 🌅 黎明 | 游戏小时跨 6:00（`_is_dawn_boundary` 已有）| 全量大整理（含归档压缩）|
| 🍃 空闲 | `SCHED` 队列深度全 0 且静置 ≥ N tick（`/api/stats.scheduler.depth` 已有指标）| 小整理：滚窗自主日志→摘要 |
| ⏰ 快满 | 记忆卡 token 估算 ≥ 阈值（`agent/memory/compressor.py` 有 token 估算可借鉴）| 应急：归纳分层腾空间 |

## 3. 验收标准（全过才算完）

1. **归档压缩**：`rotate_world_log`（D1 从"留全量"解锁）——🌟 逐行入档不变；
   🌗 段压成 `<i>: [自主摘要] ...` 一行（`summarize_autonomous` 已有）；游标
   `_log_offset` 逻辑条数不变，冷段 since 回放不炸（改后 `/api/events` 旧客户端零感知）
2. **归纳分层**：管家跑一遍 → 流水账降级/合并、`mtype` 三分类自动重判定
   （重用 `_parse_typed_reflection` 语义）、产出带**整理报告**（`npc/store/{id}_report.jsonl`
   追加：改了哪条/为什么——查得回滚得回）
3. **保护红线**：importance≥8 / category=reflection|consolidated / 标记 `pinned:true`
   的条目管家**只读不动**；人工编辑与证据链永不物理删除（只降级→归档）
4. **触发纪律**：管家内 LLM 调用**必须**走 `SCHED.invoke(P_REFLECT)` 且整批
   `asyncio.to_thread`（§19 反思冻循环教训）；流民（ephemeral）全跳过
5. 新增测试 ≥12 例（触发判定/归档压缩/游标回放/红线不动/pin/报告追加/流民跳过）；
   全量 ≥ **748 passed**；§26 把"压缩日记摘要留给管家"的挂账关掉

## 4. 技术要点（已探明）

- 复用句柄：`npc/world.py::log_tier/summarize_autonomous`、`memory.py::_tokenize/_canonical_terms`、
  `memory_card.py::update_persona_profile/_parse_typed_reflection`、`server.py::_game_hour_now/_dawn_persona_batch/_is_dawn_boundary`
- 调度指标：`SCHED.depth` + `/api/stats.scheduler`（§19.4）基本满足"空闲"判定
- 归档路径：`npc/store/log_archive/log_archive.jsonl`（现有），压缩行格式保持
  `{"i","text"}` 两键（回放器兼容）
- **别动**：安检门/协议/日志写入格式；`maybe_reflect` 的 20 tick 体检保持原频率
  （§26 已裁决：零 LLM 档频率不动）

## 5. 风险与对策

| 风险 | 对策 |
|---|---|
| 压缩摘要行被 `_parse_log_line` 误解析成事件 | 摘要行前缀 `[自主摘要]` 不入 5 格式正则；交付前跑 events 回归 |
| 管家 LLM 触发慢阻对话 | 一切 LLM 走 SCHED+P_REFLECT（低于对话优先级）；空闲触发天然避开 |
| 整理误删玩家重要记忆 | 红线段铁律+报告+pin；只降级不删除是硬约束（验收 3 项有明确测试）|
